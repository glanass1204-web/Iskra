ИСКРА 1.3 — КОНСТРУКТОР МАКРОСОВ VBA БЕЗ ИНТЕРНЕТА

- Пишете задачу обычными словами, по шагам через запятую — Искра собирает готовый макрос
  для Excel или Word из проверенных блоков, подставляя ваши столбцы, тексты, числа, цвета.
  Пример: «удалить пустые строки, выделить повторы в столбце B красным, отсортировать по столбцу A».
- Слева показано, как понята задача: шаги, предупреждения («столбец не указан — взяла A»)
  и части, которые не поняты и в макрос не вошли.
- Excel (24 действия): пустые строки, повторы (выделить/удалить), сортировка, разнести строки
  по листам, каждый лист в отдельный файл, собрать листы или файлы папки в один, оглавление,
  итог, нумерация, шапка с фильтром, ширина столбцов, пробелы, регистр, формулы в значения,
  выделить больше/меньше, просроченные даты, удалить строки по условию, PDF, защита, и др.
- Word (15 действий): замена текста, двойные пробелы, пустые абзацы, шрифт, поля по ГОСТ,
  интервал, номера страниц, оформление таблиц, маркер, принять исправления, PDF, «N сут.» + N…
  С фразой «во всех документах папки» макрос обрабатывает все .docx папки и сохраняет копии
  в подпапку «Обработано Искрой» — оригиналы не меняются.
- В каждом макросе: обработка ошибок с названием шага, сообщение «Готово», комментарии по-русски.
- «Проверить код»: незакрытые If/For/With/Sub, необъявленные переменные, типографские кавычки,
  As Integer, повторяющиеся имена процедур — строки с ошибками подсвечиваются.
- «Исправить автоматически»: кавычки, Integer → Long, Option Explicit, объявление переменных,
  переименование повторов.
- «Была ошибка при запуске»: вставьте текст ошибки (рус./англ.) — объяснение причины и что сделать
  для ошибок 1004, 9, 13, 91, 424, 438, 6, 11, 53, 70/75/76, 4605, 5941, «Variable not defined»,
  «Ambiguous name», «макросы отключены» и др.

Исправлено: экспорт .bas из библиотеки макросов был в UTF-8 — редактор VBA при импорте
показывал русские буквы как «РЎ…». Теперь .bas сохраняется в Windows-1251 с именем модуля.
