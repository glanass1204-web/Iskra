ИСКРА 0.9 — локальная интеграция GigaChat

Это ИСХОДНЫЙ КОД, не готовый EXE. Нейросеть и llama.cpp НЕ вложены в архив.

Для полностью автономной сборки заранее (на разрешённом компьютере с интернетом):
1. Получить Windows x64 CPU llama-cli.exe и необходимые DLL из официальных выпусков llama.cpp:
   https://github.com/ggml-org/llama.cpp/releases
   Использовать достаточно новую версию, поддерживающую GigaChat 3.1.
2. Поместить llama-cli.exe и необходимые DLL в папку engine рядом с Iskra.exe.
3. Скачать GGUF Q4_K_M (около 6.47 ГБ) из:
   https://huggingface.co/SergeyLizin/GigaChat3.1-10B-A1.8B-GGUF
   Поместить .gguf в папку models рядом с Iskra.exe.
4. Собрать приложение на Windows x64 через build_windows.bat (на компьютере сборки нужен Python и зависимости).
5. Перенести целиком папку dist/Iskra с подпапками engine и models на рабочий компьютер.
6. Открыть «ИИ GigaChat», выбрать исходные документы, задать задачу и проверить результат.

ВАЖНО:
- В программе отсутствуют облачные API и сетевые вызовы к модели. Локальный CLI не требует интернета.
- Сетевую изоляцию стороннего llama.cpp нужно дополнительно проверять и при необходимости блокировать брандмауэром.
- Исходные документы читаются без изменения. Нейросеть может ошибаться: её вывод — проект, не подтверждённые данные.
- Поддерживаются только документы с извлекаемым текстом; сканированные PDF не распознаются.
- Размер исходного контекста ограничен, длинные документы могут обрезаться.
- Не переносите служебные файлы на личный компьютер и не скачивайте сторонние бинарники на рабочий ПК без разрешения организации.
