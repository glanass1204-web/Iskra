# Искра: повторная проверка 0.5 (21.10.2026)

## Исправлено в исходниках
- Данные индекса и настройки теперь хранятся в `data/` рядом с EXE (либо в `ISKRA_DATA_DIR`), а не по умолчанию в `%LOCALAPPDATA%`. Для переносной папки нужен доступ на запись.
- При ошибках обхода подпапок `os.walk` больше не удаляет из индекса документы, которые могли стать временно недоступны.
- Python-модули проходят compileall.

## Выявленные ограничения (ещё не исправлены)
- Нет настоящей локальной языковой модели: генерация телеграмм и произвольных VBA-макросов отсутствует.
- Нет полноценной орфографической проверки и сравнения с утверждённым шаблоном.
- Нет Office-надстроек, макросы пока только экспортируются в .bas.
- Поиск работает по тексту и может не находить документы по одному только названию файла.
- Поиск в основном потоке интерфейса может кратковременно блокировать окно.
- В PDF без текстового слоя поиск невозможен без OCR; старые .doc/.xls/.ppt не поддержаны.
- Индексация больших XLSX может быть медленной, а ячейки с формулами могут содержать не рассчитанные значения.
- Изменения файлов обнаруживаются периодическим обходом, а не мгновенными событиями ОС.
- Отсутствует проверенный EXE для Windows x64 и тест с реальными файлами.
- Нельзя гарантировать нулевую сетевую активность всех компонентов без испытаний и правил брандмауэра.

## Что полезно добавить без переписывания ядра
1. Профили телеграмм: утверждённые образцы, реквизиты, версии, обязательные поля.
2. Проверка перед выпуском: даты, номера, адресаты, повторяющиеся фразы, нераскрытые сокращения, расхождения фактов.
3. Источники в каждом ответе: имя файла и фрагмент, на котором основано утверждение.
4. Сравнение редакций Word, журнал изменений и откат.
5. Excel: просмотр диапазона, построение формулы с тестом на копии, объяснение формулы, пакетная обработка.
6. Кнопка «Найти похожие», фильтры по дате, типу и папке, избранное и сохранённые запросы.
7. Обновление индекса по событиям файловой системы + контрольная сверка раз в 15 минут.
8. Защита от повторной обработки, исключения папок, журнал ошибок, индикатор прогресса и пауза.
9. Подключаемый локальный LLM с ограничением контекста и ссылками на документы; офлайн-модуль орфографии.
10. Надстройки Office как необязательный отдельный модуль с проверкой разрешений организации.

Безопасность: не изменять оригиналы; не исполнять сгенерированный VBA автоматически; все изменения подтверждаются пользователем. Для служебных документов требуется согласование с правилами организации.
