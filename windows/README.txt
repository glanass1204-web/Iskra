ИСКРА — локальный поиск по документам, прототип 0.2

ЧТО УЖЕ ЕСТЬ
- Русское окно, выбор папки, повторное индексирование, поиск по словам.
- DOCX, XLSX, PPTX, текстовые PDF, TXT, MD, CSV.
- Просмотр найденного фрагмента, открытие оригинала, копирование, экспорт текста в DOCX.
- Справочник формул Excel.
- Все данные хранятся локально: %LOCALAPPDATA%\IskraLocal\index.sqlite3.
- Оригиналы программа не изменяет.

ЧЕГО ПОКА НЕТ
- Встроенной нейросети, генерации официальных ответов, свободного диалога.
- Настоящих надстроек Word/Excel и обработки выделения из Office.
- OCR для сканированных PDF; старые DOC/XLS/PPT не поддерживаются.
- Готового Windows EXE в этом архиве: здесь исходники и сценарий сборки.

КАК ПОЛУЧИТЬ ПЕРЕНОСНУЮ ПРОГРАММУ
1. На доверенном компьютере Windows 10/11 x64 с интернетом установите Python 3.11+.
2. Запустите build_windows.bat. Он скачает зависимости и создаст папку dist\Iskra.
3. Скопируйте ВСЮ папку dist\Iskra на флешку. На рабочем ПК запускайте Iskra.exe.
4. На рабочем ПК не нужен Python или интернет. Права администратора обычно не нужны,
   но политики безопасности организации могут запретить запуск.
5. Внимание: собранный EXE необходимо проверить на Windows x64 до использования.

ИНТЕГРАЦИЯ С WORD/EXCEL
Сейчас: выделение текста в Office -> Ctrl+C -> вставка в Искру для поиска,
и обратно; найденные документы открываются обычным двойным кликом.
План: отдельные кнопки Word/Excel (через одобренные IT-отделом надстройки),
которые передают выделенный текст локальному приложению без облака.

БЕЗОПАСНОСТЬ
Не переносите рабочие документы, индекс или модель на личные устройства без разрешения.
Индекс содержит извлечённый текст документов; храните его в защищённом профиле.
Программа не передаёт данные в сеть, но запуск стороннего ПО требует согласования с IT.

БИБЛИОТЕКА МАКРОСОВ (версия 0.4)
В главном окне кнопка «Библиотека макросов»: готовые VBA для Word/Excel,
просмотр, копирование и экспорт в .bas. Для подключения в Office:
Alt+F11 → Файл → Импорт файла → выберите .bas.
Сохраните копию документа как .docm / .xlsm, если нужно хранить макрос.
Не включайте макросы вопреки политикам безопасности организации.
Макросы не выполняются Искрой автоматически; сначала тестируйте на копиях.
ВНИМАНИЕ: интеграция кнопок непосредственно в ленту Office и генерация
произвольного VBA локальной нейросетью ещё НЕ реализованы.
Готовый Windows EXE здесь НЕ приложен: сборка build_windows.bat требует
Windows 10/11 x64, Python и установленных зависимостей на СБОРОЧНОМ ПК.
На рабочем ПК после сборки Python не нужен.
