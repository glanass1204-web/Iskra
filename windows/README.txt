ИСКРА 1.6 ДЛЯ WINDOWS — поиск и помощник по документам без интернета

ДВЕ ВЕРСИИ (обе работают без интернета):
- с нейросетью: Iskra-Windows-AI-chast-1.zip + Iskra-Windows-AI-chast-2.zip — распаковать ОБА в одну папку;
- без нейросети: Iskra-Windows.zip.

ЧТО УМЕЕТ
- Нейросеть (версия AI): «напиши …» — черновик по найденным документам; вопрос «…?» — ответ по документам
  с источником; в редакторе телеграмм — официальный стиль, сократить, исправить ошибки.
- Первый запуск: сама предлагает папки (Документы, Рабочий стол, сетевые диски). Обзор папок: виды документов,
  темы, от кого, сроки, последние телеграммы.
- Поиск по DOCX, XLSX/XLSM, PPTX, текстовым PDF, TXT, MD, CSV в выбранных папках
  (по тексту и по имени файла, ё/е и окончания не мешают). Индекс обновляется раз в 15 минут.
- Помощник (вкладка «Помощник»): «найди …», «кратко», «сроки», «кто», «номера», «суммы»,
  «контакты», «ближайшие сроки», «формула …». Отвечает только тем, что написано в документах.
- Контроль сроков по всем документам: просроченные и ближайшие 30 дней.
- Входящие: слежение за папкой, разбор каждого нового файла (вид, номер, от кого, срок), уведомления,
  ответ телеграммой и напоминание в один щелчок.
- Свод таблиц Excel по организациям: 5 и больше таблиц в одну (по списку, на лицо…), итог, проверка,
  заполнение готовой формы, доклад телеграммой по своду.
- Составление телеграмм по видам: доклад, указание, запрос, напоминание, ответ по пунктам входящей.
- Проверка орфографии без интернета (русский словарь + типичные канцелярские ошибки).
- Word → Excel: из многих документов одна таблица (поля находятся сами или собираются таблицы).
- Excel → Word: документы по образцу — каждая строка Excel становится документом.
- Объединение 3–5 похожих телеграмм в одну: без повторов, только главное, одна подпись,
  оформление по одному шаблону (ГОСТ или свой бланк), исправление типовых ошибок.
- Формулы Excel: подбор с вашими столбцами и условиями, объяснение любой формулы.
- Конструктор макросов VBA: задача словами — готовый макрос; проверка и исправление ошибок.
- Сводная Excel по шаблону, сравнение редакций, редактор телеграмм, макросы VBA, история.
- Все данные хранятся в папке data рядом с Iskra.exe. Исходные файлы не изменяются.

УСТАНОВКА
1. Скачайте Iskra-Windows.zip:
   https://github.com/glanass1204-web/iskra/releases/download/iskra-windows-latest/Iskra-Windows.zip
2. Распакуйте папку Iskra целиком (на диск или флешку) и запустите Iskra.exe.
   Python, интернет и права администратора не нужны.
3. Нажмите «Папки…» → «Добавить папку» и выберите папку с документами.
   Первое индексирование тысяч файлов может занять несколько минут — окно при этом работает.

СБОРКА ИЗ ИСХОДНИКОВ
build_windows.bat на Windows 10/11 x64 с Python 3.11+.

ОГРАНИЧЕНИЯ
- Сканы PDF без текстового слоя не распознаются (нет OCR); старые DOC/XLS/PPT не поддерживаются.
- Помощник работает по правилам, а не нейросетью: понимает перечисленные команды, свободный диалог не ведёт.
- Орфография проверяется по словарю: редкие термины и аббревиатуры добавьте в словарь кнопкой
  «Добавить в словарь». Пунктуация (запятые) проверяется только для частых случаев.
- Надстроек в ленте Word/Excel нет: макросы экспортируются в .bas и подключаются вручную.

БЕЗОПАСНОСТЬ
Программа не обращается в сеть. Перед использованием на рабочем компьютере согласуйте запуск
стороннего ПО с IT-отделом.
Не переносите рабочие документы и индекс на личные устройства без разрешения.
