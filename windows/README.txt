ИСКРА 1.0 ДЛЯ WINDOWS — локальный поиск по документам и GigaChat без интернета

ЧТО УМЕЕТ
- Поиск по DOCX, XLSX/XLSM, PPTX, текстовым PDF, TXT, MD, CSV в выбранных папках
  (по тексту и по имени файла, ё/е и окончания не мешают). Индекс обновляется раз в 15 минут.
- ИИ GigaChat офлайн: проект ответа строго по выбранным документам, с пометками НЕ НАЙДЕНО
  и ТРЕБУЕТ ПРОВЕРКИ. Работает на процессоре, без интернета и облака.
- Сводная Excel по шаблону, сбор полей Word ↔ Excel с указанием источника каждого значения.
- Сравнение редакций, редактор телеграмм, формулы Excel, библиотека VBA-макросов, история.
- Все данные хранятся в папке data рядом с Iskra.exe. Исходные файлы не изменяются.

УСТАНОВКА (готовая сборка)
1. Скачайте Iskra-Windows.zip:
   https://github.com/glanass1204-web/iskra/releases/download/iskra-windows-latest/Iskra-Windows.zip
2. Распакуйте папку Iskra целиком (на диск или флешку) и запустите Iskra.exe.
   Python не нужен. Движок llama.cpp уже лежит в папке engine.
3. Для GigaChat скачайте модель (около 6,5 ГБ) на компьютере с интернетом:
   правой кнопкой по get_model.ps1 → «Выполнить с помощью PowerShell»,
   или вручную файл GigaChat3.1-10B-A1.8B-q4_K_M.gguf с huggingface.co/ai-sage/GigaChat3.1-10B-A1.8B-GGUF
   в папку models. Нужно 16 ГБ оперативной памяти; ответ занимает несколько минут.

СБОРКА ИЗ ИСХОДНИКОВ
build_windows.bat на Windows 10/11 x64 с Python 3.11+, затем get_engine.ps1 и get_model.ps1.

ОГРАНИЧЕНИЯ
- Сканы PDF без текстового слоя не распознаются (нет OCR); старые DOC/XLS/PPT не поддерживаются.
- Ответ нейросети — проект: проверяйте факты по оригиналам.
- Надстроек в ленте Word/Excel нет: макросы экспортируются в .bas и подключаются вручную.

БЕЗОПАСНОСТЬ
Программа не обращается в сеть. Перед использованием на рабочем компьютере согласуйте запуск
стороннего ПО с IT-отделом; при необходимости запретите engine\*.exe доступ в сеть брандмауэром.
Не переносите рабочие документы, индекс и модель на личные устройства без разрешения.
