Искра 1.9.1 — уточнения правят прошлый ответ, а не начинают заново

ОБНОВЛЕНИЕ: замените только Iskra-AI-chast-01.zip. Остальное не меняется.

- После ответа нейросети можно просто написать, что поменять: «сделай короче», «поменяй срок на 30.10.2026»,
  «добавь пункт о технике», «адресат — начальник штаба», «убери второй пункт». Искра правит ЭТОТ ЖЕ текст
  (черновик в открытом редакторе меняется на месте, Ctrl+Z — вернуть), а не ищет документы заново.
- Уточняющие вопросы продолжают разговор по тем же документам: «а кто подписал?», «а срок какой?».
- Формулу тоже можно уточнить: «а если по столбцу D», «только для полигона».
- Начать заново: «новое: …» или любая новая команда («найди …», «сводка»).
- В редакторе телеграмм: «Нейросеть ▾ → Поправить своими словами…».
- В окне Ctrl+Alt+Пробел: поле «Поправить» — уточнять результат перед вставкой.
- Пишет по ВСЕМ подходящим документам, а не по одному-двум: собирает до 12 документов из нескольких
  поисков (все слова, главные слова, по смыслу, любое слово). Если всё сразу не помещается — сначала делает
  выписку из каждого документа («читаю документы: 3 из 12»), потом пишет по выпискам. В чате видно, какие
  документы взяты. «найди …», затем «напиши … по найденным» — возьмёт все документы из списка слева.
- Старые даты: нейросеть знает сегодняшнюю дату; дата телеграммы — сегодняшняя; прошедшие сроки из старых
  документов не переносятся — вместо них [УТОЧНИТЬ: срок — в документах было …, он уже прошёл].
  Ссылки «На № … от …» со старой датой остаются (это правильно). У каждого документа нейросеть видит дату файла.
- Исправлено: кнопка «Кто» (ФИО из документа) открывала справочник людей.
