# Искра — архитектура и функции

## Реализовано в исходном прототипе 0.3
- Поиск SQLite FTS5 и чтение DOCX/XLSX/PPTX/PDF/TXT/CSV/MD.
- Выбор нескольких папок; настройки сохраняются локально.
- При запуске и далее раз в 15 минут проверяются новые, изменённые и удалённые файлы.
- Отдельный редактор проекта телеграммы, сохранение в новый DOCX, простые предэкспортные проверки.
- Подбор нескольких типовых формул Excel по ключевым словам (не универсальный ИИ).
- Нет встроенных сетевых вызовов и облачных API.

## Спроектировать отдельными модулями до промышленного использования
1. Локальный LLM GGUF (CPU) с ограничением контекста, ссылками на исходники и отказом выдумывать факты.
2. Нормализация телеграмм по **утверждённым пользователем** DOCX-шаблонам; контроль реквизитов, сроков, адресатов, дубликатов и противоречий.
3. Локальная орфография, грамматика и сравнение изменений «до/после».
4. Office: отдельные надстройки Word/Excel (с учётом ограничений корпоративных политик), без скрытых правок.
5. Excel: чтение выделения, проверка формулы на тестовых строках, резервная копия перед записью.
6. Фильтры поиска: тип, дата, автор, тема, подразделение; поиск похожих и дублирующихся документов.
7. Журнал источников и действий; экспорт результата в DOCX/XLSX/PDF; версии черновиков.
8. Контроль доступа, шифрование локального индекса при необходимости, ручная очистка базы.
9. Инкрементальное индексирование в фоне с очередью, прогрессом, журналом ошибок и ограничением CPU.
10. Поддержка старых DOC/XLS и сканов через отдельные офлайн-конвертеры/OCR (по разрешению).
11. Надёжная сборка Portable для Windows 10 x64, автотесты и тест без сетевых подключений.

## Границы текущей версии
Не собран и не протестирован Windows EXE. Не интегрирован в Word/Excel. Нет локальной LLM и полноценной проверки орфографии. При первом запуске Python-версии нужны установленные библиотеки. Программа не предназначена для секретных документов без одобрения организации и оценки защиты.
