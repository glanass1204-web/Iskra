# Искра

Настоящее Android-приложение персонального помощника «Искра» на Kotlin и Jetpack Compose.
Сделано для Samsung Galaxy S26 Ultra, работает на любом телефоне с Android 8.0 и новее.

## Установка на телефон

1. Открой на телефоне:
   `https://github.com/glanass1204-web/iskra/releases/download/iskra-latest/iskra.apk`
   (или вкладка **Releases** репозитория → «Искра — последняя сборка» → `iskra.apk`).
2. Открой скачанный файл. Samsung попросит разрешить установку из этого источника — разреши для браузера или «Моих файлов».
3. Если Play Защита покажет предупреждение о неизвестном приложении, нажми «Подробнее» → «Всё равно установить».
4. Запусти Искру и разреши микрофон и уведомления. Остальные разрешения (звонки, СМС, контакты) она спросит, когда понадобятся.

Новые версии ставятся поверх старой, данные сохраняются.

### Голос без интернета

Настройки → Общие настройки → Голосовой ввод (или «Распознавание речи») → скачай **русский** офлайн-пакет.
Для озвучки: Настройки → Специальные возможности → Преобразование текста в речь → русский голос.

### Быстрый вызов

- **Боковая кнопка:** Настройки → Дополнительные функции → Боковая кнопка → Двойное нажатие → Открыть приложение → Искра. В настройках Искры включи «Слушать сразу при открытии».
- **Плитка в шторке:** потяни шторку → ✎ → перетащи плитку «Искра». Касание — и она слушает.
- **Ярлык:** долгое нажатие на иконку → «Сказать Искре».
- Искра также объявлена как помощник (`ACTION_ASSIST`) — если One UI покажет её в списке «Цифровой помощник», можно выбрать её там.

## Что умеет

| Возможность | Без интернета | Как сказать |
| --- | --- | --- |
| Голос на русском | да, с офлайн-пакетом | кнопка микрофона |
| Память | да | «Запомни, что…», «Что ты помнишь?», «Забудь…» |
| Задачи | да | «Задача…», «Мои задачи», «Готово 2» |
| Напоминания — срабатывают, даже если Искра закрыта и после перезагрузки | да | «Напомни через 15 минут…», «Напомни завтра в 9…» |
| Звонки, в том числе по имени из контактов | да, **с подтверждением** | «Позвони маме», «Позвони 8999…» |
| СМС — отправляются сами | да, **с подтверждением** | «Напиши смс маме буду в 7» |
| Будильник, таймер | да | «Будильник на 7:30», «Таймер на 5 минут» |
| Фонарик, громкость, вибрация | да | «Включи фонарик», «Громче», «Без звука» |
| Открыть приложение | да | «Открой Телеграм» |
| Wi‑Fi, Bluetooth, интернет | да (открывает панель) | «Включи вайфай» |
| Камера, карты, заряд батареи | да | «Открой камеру», «Маршрут до…», «Заряд батареи» |
| Заработок по проектам | да | «Доход 5000 проект Сайт», «Расход 300», «Баланс» |
| Погода (Open-Meteo), курсы ЦБ, новости (Лента, РИА, ТАСС) | нет, VPN не нужен | «Какая погода завтра», «Курс доллара», «Новости» |
| Ответы на вопросы: Википедия и веб-поиск | нет, VPN не нужен | «Кто такой…», «Найди…», любой вопрос |
| Калькулятор, анекдоты, монетка | да | «Сколько будет 25 на 4», «Расскажи анекдот» |
| Мониторинг (проверка каждые 6 часов при наличии сети, уведомление об изменениях) | нет | «Следи за…», «Проверь мониторинг» |

На вопрос «Подтверди действие» можно ответить голосом: «да» или «нет».

## Ключи не нужны

Искра ищет информацию сама в источниках, которые работают в России без VPN. Ключ Claude API — необязательное дополнение
для свободного разговора; из России сервис Claude доступен только через VPN, а без связи с ним Искра просто ищет сама.

## Голос

«Настройки» → «Голос Искры»: выбери программу озвучки, русский голос, скорость и тон. Больше голосов даёт бесплатная
программа RHVoice (работает без интернета) — после установки она появится в списке.

## Приватность и безопасность

- Все данные хранятся в закрытой папке приложения на телефоне. Экспорт и полное стирание — в «Настройках».
- Звонки, СМС и удаление записей — только после подтверждения.
- Включить Wi‑Fi или Bluetooth сама Искра не может: начиная с Android 10 это разрешено только пользователю, поэтому она открывает нужную панель.
- Приложение подписано ключом `app/iskra.keystore`, который лежит в репозитории, чтобы обновления ставились поверх. Если репозиторий публичный,
  для полной защиты создай свой ключ и передай его сборке через переменные `ISKRA_KEYSTORE_FILE`, `ISKRA_KEYSTORE_PASSWORD`, `ISKRA_KEY_ALIAS`, `ISKRA_KEY_PASSWORD`
  (после смены ключа старую версию придётся удалить один раз).

## Ограничения

- Нет постоянного прослушивания слова «Искра» в фоне — это сильно сажает батарею. Вызов — боковой кнопкой, плиткой или иконкой.
- Без интернета нет большой нейросети: работают команды, память, задачи, напоминания, деньги и функции телефона.

## Для разработчика

```
├── core/   чистый Kotlin: понимание команд (Brain), данные (Store), Claude и поиск (Online) + тесты
└── app/    Android: экран на Compose, голос, звонки/СМС/фонарик, напоминания (AlarmManager), мониторинг (WorkManager)
```

- Тесты ядра: `./gradlew :core:test`
- Сборка: `./gradlew :app:assembleRelease` (нужен Android SDK)
- Веб-версия (PWA) лежит в папке `web/`.
- GitHub Actions (`.github/workflows/build.yml`) собирает APK при каждом изменении и публикует его в релиз `iskra-latest`.
