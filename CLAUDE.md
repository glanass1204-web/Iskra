# Искра — правила проекта

Искра — офлайн-помощник штаба воинской части для Windows: телеграммы, указания, рапорты, отпускные билеты,
сводные таблицы, уставы. Код программы — `windows/` (Python, Tkinter, собирается PyInstaller'ом).
Остальное в репозитории (`app`, `core`, `web`, gradle) к Искре для Windows не относится.

## Условия работы
- Без интернета. Рабочий ПК: 16 ГБ памяти, только процессор. Нейросеть — Qwen3.5-4B (llama.cpp), основная.
  Другие модели проверены и не лучше: Qwen3.5-9B, Gemma 4 E4B, GigaChat (выдумывает) — не предлагать.
- Пользователь скачивает ТОЛЬКО `Iskra-AI-chast-01.zip` (программа). Части 02–10 (модель) не меняются.
- Пользователь пишет по-русски, кратко. Отвечать по-русски, без технических подробностей.

## Что делать и чего не делать
- Не делать: боевые распоряжения, схемы, нитки, помощник по БПЛА/FPV (отказано). Секретные документы —
  только на сертифицированных средствах, Искра для них не предназначена.
- Телеграммы: БЕЗ шапки («ТЕЛЕГРАММА», «Кому:», «Дата:», «Номер:») и БЕЗ подписи — только текст; оформление
  даёт свой шаблон пользователя (`{Текст}` в Word). Не вставлять даты, номера, подразделения, о которых не
  просили. Сколько пунктов просили — столько и пишется.
- Рапорт: «Командиру… / от … / дата», «РАПОРТ», «Настоящим докладываю…», «Прошу полагать прибывшим/убывшим»,
  «Прошу Вашего ходатайства…», подпись «звание — подпись — Фамилия». Слов «доношу», «донесение» нет.
- Шаблоны: свой для каждого вида документа (`iskra_ai.TEMPLATES`, окно «Шаблоны документов»); вид — по словам
  задания (`template_kind`). Боевые распоряжения нейросеть не составляет (`COMBAT_ORDER`).
- Перенос изменений (`iskra_highlight.py`): шаблон (вид) + документ (куда вносить) + присланные (откуда).
  Переносится всё отмеченное зелёным/салатовым, даже если текст тот же. Изменения — зелёным шрифтом.
  Шрифт и размер — строго как в шаблоне, везде.

## Каждое изменение
1. `cd windows && python3 -m pyflakes <изменённые файлы>` и все тесты:
   `python3 -m unittest discover -p 'test_*.py'` — должно быть OK.
2. На новое поведение — тест (`test_*.py`); нейросеть в тестах подменяется (`ai.run = lambda prompt, **kw: …`).
3. Поднять `VERSION` в `windows/iskra.py` и дописать раздел в `windows/CHANGELOG_v1_10_0.txt` (простым языком,
   для пользователя).
4. Выпуск — навык `iskra-release` (`.claude/skills/iskra-release/SKILL.md`).

## Отложено (пользователь сказал «пока не надо, но запомни»)
- Защита экрана, включаемая в настройках: (1) запрет скриншотов и записи экрана — `SetWindowDisplayAffinity`
  с `WDA_EXCLUDEFROMCAPTURE` (Windows 10 2004+; от фото телефоном не защищает); (2) водяной знак поверх окна:
  компьютер, пользователь, дата и время. От фото телефоном реально помогают только порядок (без телефонов),
  плёнка-фильтр и водяной знак; для ДСП/грифа — сертифицированные СЗИ (Secret Net Studio, Dallas Lock),
  Искра их не заменяет.
