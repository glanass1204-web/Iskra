# Искра — персональный ИИ-помощник

Голосовой помощник на русском языке, сделанный как веб-приложение (PWA) для Samsung Galaxy S26 Ultra.
Устанавливается на главный экран как обычное приложение, без Play Маркета.

## Что умеет

| Возможность | Без интернета | С интернетом |
| --- | --- | --- |
| Голос на русском (говорить и слушать) | да, если скачан офлайн-пакет русского языка | да |
| Память: «запомни, что…», «что ты помнишь», «забудь…» | да | да |
| Задачи: «задача…», «мои задачи», «готово 2» | да | да |
| Напоминания: «напомни через 15 минут…», «напомни в 18:30…» | да | да |
| Телефон: звонок, СМС, маршрут, заряд, вибрация | да, **только после подтверждения** | да |
| Заработок: «доход 5000 проект Сайт», «расход 300», «баланс», «идеи заработка» | да | да |
| Поиск: «найди…», «что такое…» | нет | да (Википедия или Claude с веб-поиском) |
| Мониторинг: «следи за…», «проверь мониторинг» | нет | да |
| Свободный разговор на любые темы | нет | да, с ключом Claude API |

Скажи **«что ты умеешь»**, чтобы увидеть все команды.

## Установка на телефон

1. Выложи папку `iskra/` на любой HTTPS-хостинг (GitHub Pages, Netlify, Cloudflare Pages).
   Для GitHub Pages: Settings → Pages → ветка с этой папкой, затем открой `https://<имя>.github.io/<репозиторий>/iskra/`.
2. Открой адрес в Chrome или Samsung Internet на телефоне.
3. Меню ⋮ → **«Добавить на главный экран»** / «Установить приложение».
4. Открой Искру один раз при интернете — после этого она запускается и без сети.
5. Разреши микрофон и уведомления (вкладка «Настройки» → «Разрешить уведомления»).
6. Для голоса без сети: Настройки телефона → Google → Голосовой ввод → Офлайн-распознавание → скачай «Русский».
   Для озвучки: Настройки → Специальные возможности → Синтез речи → русский голос.

Проверить на компьютере: `python3 -m http.server -d iskra 8000` и открыть `http://localhost:8000`.

## Умный режим (Claude)

Во вкладке «Настройки» можно вставить ключ Claude API (console.anthropic.com).
Тогда, если есть сеть, вопросы, которые Искра не распознала как команду, уходят в Claude
с веб-поиском, а в контексте разговора есть твоя память и задачи.
Ключ хранится только на телефоне и отправляется только в Anthropic. Запросы платные — по тарифам Anthropic.

## Безопасность и приватность

- Все данные (память, задачи, деньги, история) хранятся только в браузере телефона. Экспорт и полное стирание — в «Настройках».
- Звонки, СМС, маршруты, удаление записей и стирание данных выполняются **только после подтверждения** в диалоге.
- СМС не отправляется само: Искра открывает приложение сообщений с готовым текстом, отправляешь ты.

## Честные ограничения

Это веб-приложение, а не системный ассистент Android, поэтому:

- Напоминания срабатывают, пока Искра открыта или висит в недавних приложениях. Для важного дублируй будильником.
- Нет фонового прослушивания по слову «Искра» — нажимай на кнопку микрофона.
- Доступны только функции, которые браузер разрешает веб-приложениям (звонок, СМС, карты, вибрация, батарея, уведомления).
  Управление настройками, приложениями и файлами телефона потребует нативного Android-приложения — это следующий шаг.
- Без интернета нет «большой» нейросети: работают команды, память, задачи, напоминания и учёт денег.

## Файлы

- `index.html`, `styles.css` — интерфейс
- `app.js` — чат, голос, напоминания, вкладки, настройки
- `brain.js` — локальное понимание команд на русском (работает офлайн)
- `claude.js` — умный режим через Claude API
- `store.js` — личная память в хранилище телефона
- `sw.js`, `manifest.webmanifest`, `icon.svg` — установка и офлайн-работа
